Carnet. Aide

Carnet (iPhone) lit l’étiquette d’un produit, vous prévient selon les alertes que vous réglez, et tient le journal de vos repas sur votre iPhone. Pas de compte.

Une question ? Écrivez à contact@livradom3fi.fr (réponse par e-mail).

Scanner un produit

Touchez « Scanner » et visez le code-barres. Si la caméra n’y arrive pas, tapez les chiffres sous le code, ou lisez le code sur une photo.

Un produit absent de la base de Carnet est demandé à Open Food Facts (base collaborative) : il faut alors une connexion. Seul le code-barres est envoyé.

Alertes allergènes

Dans Moi › Mes alertes, touchez les allergènes qui vous concernent. Carnet signale ce qu’il repère dans le texte disponible : « Contient » quand la fiche Open Food Facts déclare l’allergène, « Possible » quand il repère un mot dans la liste d’ingrédients (le mot trouvé est affiché), et les mentions « peut contenir » ou « traces de ».

Cette lecture automatique peut se tromper, dans un sens comme dans l’autre : Carnet n’affirme jamais qu’un produit est sans allergène. Quand il ne repère aucun de vos allergènes, il l’écrit : « Carnet n’a rien repéré dans le texte disponible. » Quand rien n’est connu : « Allergènes inconnus pour ce produit — lisez l’emballage. » Les traces déclarées par la fiche sont toujours affichées. L’emballage fait toujours foi.

Mon carnet sur ce téléphone

Tout reste sur votre iPhone. Dans Moi › Mon carnet sur ce téléphone, vous pouvez enregistrer une sauvegarde (fichier complet, historique compris, gratuit), restaurer, exporter en tableau ou effacer tout le carnet.

En changeant de téléphone, enregistrez une sauvegarde dans Fichiers ou iCloud Drive, puis restaurez-la sur le nouvel iPhone.

Carnet+

Carnet+ (abonnement App Store, mensuel ou annuel) ouvre le détail des jours passés, la vue semaine, le suivi du poids et le détail des macros. Sans abonnement, rien n’est perdu.

Gérer ou résilier : écran Carnet+ › « Gérer l’abonnement », ou Réglages de l’iPhone › votre nom › Abonnements. Après une réinstallation : « Restaurer mes achats ».

L’abonnement Carnet+ de l’ancienne version web (paiement par carte) est distinct de l’abonnement iPhone et n’ouvre pas Carnet+ dans l’appli iPhone. Pour le résilier, écrivez à contact@livradom3fi.fr.
